# Password Generator

Dieses Projekt ist ein Lernprojekt in Python.

Der Code basiert auf einem Beispiel aus einem Lehrbuch
und wurde zum Verständnis selbst abgetippt.

Ziele des Projekts:
- Grundlagen von Python üben
- Funktionen und Kontrollstrukturen verstehen
- Git und GitHub praktisch anwenden

Geplante Weiterentwicklung:
- Umbau zu einem Rezept-Generator
- Erweiterung um Zutaten
- Später: Kochzeit, Filter, ggf. GUI
